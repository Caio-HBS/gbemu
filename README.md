# Game Boy Emulator in Java

A Game Boy emulator implementation in Java, following the tutorial series by @gamingmonsteruniversity.

## About

This project is a Java port of a Game Boy emulator, based on the YouTube
tutorial: https://www.youtube.com/watch?v=e87qKixKFME

The emulator aims to accurately recreate the functionality of the original Nintendo Game Boy hardware.

## Development Status

Currently in early development stage.
